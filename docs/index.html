Firmware Flasher

This page requires Chrome or Edge (version 86 or later). It uses the File System Access API to write directly to the board's bootloader drive. Firefox and Safari do not support this API.

How to flash

  1. Double-click the reset button on your Grand Central M4 Express until the NeoPixel pulses green. A drive named GRANDCNT will appear on your computer.
  2. Click the button for your PCB version below.
  3. In the dialog that opens, navigate to and select the GRANDCNT drive, then click Open (macOS) or Select Folder (Windows).
  4. Wait for the confirmation message. The board reboots automatically — do not unplug while writing.
Revised PCB (v2) Sliders 12 and 13 in correct A3/A2 order. Use this if you have the updated board.
Original PCB (v1) Sliders 12 and 13 wired A2/A3 swapped. Use this if you have the original board.
